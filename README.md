# Elijo Odontomar — Odontología Integral & Estética Dental

Sitio web oficial y landing page de alta conversión para Elijo Odontomar en Santo Domingo.

## ✨ Características Principales
- **Hero Section Editorial**: Tipografía de alto contraste, fotografía dental y propuesta de valor enfocada en salud bucal integral y estética dental.
- **Identidad de Marca Oficial**: Isotipo de diente y ola marina en aguamarina oceánico (`#20cdd4`), negro carbón (`#111827`) y blanco puro.
- **Tratamientos Dentales**: Profilaxis, restauraciones estéticas, salud gingival, prótesis y coronas armónicas.
- **Antes y Después Interactivo**: Comparador visual (.cmp) fluido y táctil de transformaciones de sonrisa.
- **Agendamiento Directo a WhatsApp**: Modal de reserva rápida que envía los datos del paciente y motivo de consulta automáticamente.
- **100% Responsive & Accesible**: Optimizado para teléfonos móviles, tablets y computadoras.
